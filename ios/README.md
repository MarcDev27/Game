# Backup 7105 for iPhone

The App Store version of Backup 7105. It is a native iOS app (Swift, UIKit) that runs the game
from this repository in a full-screen web view. The game files are bundled inside the app, so it
works offline and never loads code from the internet. The web version on GitHub Pages and the
app always run the same game: every build copies `index.html`, `styles.css`, `src/` and `icons/`
into the app.

## What the app adds

- **iPhone Duo, natively.** Built with the iOS 27.1 SDK, the app fills the whole display, both
  closed and open, in every pose. There is no letterboxing and no side strip. While the phone is
  partly folded, UIKit reports the hinge (`UIView.reservedRegions(kind: .division)`) and the game
  lays itself out around it:
  - **Book pose** (vertical hinge): controls stay off the fold.
  - **Laptop pose** (horizontal hinge): the game is on top and the controls are below, like a
    handheld console.

  Settings → Fold layout → Auto follows the hinge. The manual Book/Laptop/Off choices and the
  Fold position slider still work.
- **Safe saves.** Every change to the saves is copied into the app's own storage (Application
  Support), which iOS includes in iCloud and computer backups of the device. If the web view's
  storage is ever cleared, the game restores the saves from that copy on the next launch. The
  previous copy is kept too.
- **Native share sheet** for "Back up all saves" (Save to Files → iCloud Drive, AirDrop, …).
- **Haptics** when you take damage, die, trigger explosions, wake a boss or level up. They can be
  turned off in Settings.
- Full-screen game behavior:
  - no status bar, and the home indicator fades;
  - edge swipes go to the game first;
  - no zooming or scrolling;
  - sound respects the Ring/Silent switch and mixes with your music.

## Requirements

- **Xcode 27.1 or later.** Only apps built with the iOS 27.1 SDK fill the iPhone Duo display;
  older SDKs letterbox the app on the inner display. Xcode 27.1 also has the iPhone Duo
  simulator.
- **iOS 17 or later** on the device (the game needs modern Safari features such as compression
  streams).
- **An Apple Developer Program membership** ($99 per year) to install on your own iPhone for
  more than a week, use TestFlight and publish.

## Run it on your iPhone

1. On a Mac, open `ios/Backup7105.xcodeproj` in Xcode.
2. Select the **Backup7105** target → **Signing & Capabilities** → choose your **Team**. If Xcode
   says the bundle identifier is taken, change `com.marcdev27.backup7105` to your own reverse
   domain.
3. Connect your iPhone (or pick the iPhone Duo simulator) and press **Run**.

**Debugging:** Debug builds can be inspected from Safari on the Mac (Develop menu → your iPhone →
Backup 7105). Script errors also appear in the Xcode console, prefixed `B7105`.

## Publish on the App Store

1. **Create the app record.** In [App Store Connect](https://appstoreconnect.apple.com) → Apps →
   **+** → New App. Use:
   - platform iOS;
   - name "Backup 7105";
   - the bundle ID from step 2 above;
   - any SKU, for example `backup7105`.
2. **Fill in the listing:**
   - **Category:** Games → Adventure (secondary: Action or Role Playing).
   - **Age rating:** the questionnaire. The game has cartoon/fantasy violence; answer the
     rest honestly.
   - **App Privacy:** choose **Data Not Collected**.
   - **Privacy Policy URL:** `https://marcdev27.github.io/Game/privacy.html`. This page is part
     of this repository and is published with the game.
   - **Support URL:** for example `https://github.com/MarcDev27/Game/issues`.
   - **Description, keywords, promotional text:** describe the game in its own terms. Don't name
     Terraria or other games: App Review rejects listings that use other apps' names or
     trademarks.
3. **Screenshots.**
   - **6.9-inch iPhone:** 1320 × 2868 or 1290 × 2796 pixels. This size is required.
   - **iPhone Duo:** outer display 1398 × 2034, inner display 2007 × 2853, either orientation.
     Apple's iPhone Duo pages say these screenshots earn the "optimized for iPhone Duo" badge,
     and become required from April 2027 for apps built with the iOS 27.1 SDK.

   The iPhone Duo simulator in Xcode 27.1 takes them at the right size (File → Save Screen).
4. **Upload a build.** Either of these works:
   - **Xcode:** Product → Archive, then in the Organizer → Distribute App → App Store Connect.
   - **GitHub Actions**, no Mac needed after setup:
     1. Add the four secrets listed at the top of `.github/workflows/ios.yml`.
     2. Run the **iOS app** workflow by hand with **upload** ticked. Each run gets its own build
        number.
5. **Test with TestFlight**, ideally on an iPhone Duo in every pose: closed, open, book and
   laptop.
6. **Submit for review.** In the version page, choose the build and press **Add for Review**.
   Under Helpful Details you can mention that the app is optimized for iPhone Duo, including all
   device poses.

## Versions

- The version shown on the App Store is `MARKETING_VERSION` (1.0) in the target's build
  settings.
- The build number is `CURRENT_PROJECT_VERSION`. CI uploads set it to the workflow run number.
- Raise the version for each App Store release.

## Continuous integration

`.github/workflows/ios.yml` runs on every push that touches the app or the game. It:

1. builds the app for the iOS Simulator with the newest Xcode on GitHub's macOS runners;
2. launches it, preferring an iPhone Duo simulator when the runner has one;
3. checks that the game loaded without script errors;
4. saves a screenshot of the title screen and the build log as the `simulator-run` artifact.

If the runner's Xcode is older than 27.1, the build leaves out the hinge code and warns.
Uploads always require 27.1.
